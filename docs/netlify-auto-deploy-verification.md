# Netlify Automatic Deployment Verification

This document records the operational verification of automatic production
deployments for the Mandoob frontend.

- Netlify site: `mandoob-app`
- GitHub repository: `khawla007/mandoob-frontend`
- Production branch: `main`
- Production URL: <https://mandoob-app.netlify.app>
- Verification method: a normal push to `main`, with no manual Netlify deploy
  trigger

The associated Netlify deploy record and commit SHA are retained in Netlify's
deployment history.
